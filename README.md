#### EMBITIOUS ####

** Vector Embedding service using Java21/Quarkus **

** Containerized for Kubernetes deployment **

** use DJL library for Huggingface models **

** provides a REST and a JMS service, REST for single requests JMS for batches**

** use huggingface sentence-transformers **

** this service only creates the embedding and returns to caller or updates topic, no database or any async/blocking work **
